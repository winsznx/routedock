## 0.2.2

### Patch Changes

- [#634](https://github.com/winsznx/routedock/pull/634) [`eedb5fd`](https://github.com/winsznx/routedock/commit/eedb5fdad6ac4b4352fb5430376ad6fa22bf052e) Thanks [@TS-mfon](https://github.com/TS-mfon)! - Require the patched MCP SDK and refresh the workspace dependency graph to address published security advisories.

- [#580](https://github.com/winsznx/routedock/pull/580) [`7502381`](https://github.com/winsznx/routedock/commit/750238105902815376f38d94885d815990cf264a) Thanks [@TheWeirdDee](https://github.com/TheWeirdDee)! - `open_session` now resolves a bare provider origin to the streaming endpoint published in the provider's manifest (`endpoints.stream`, or the only endpoint), instead of sending vouchers and the closing `DELETE` to the origin itself, where they were paid for and then returned HTTP 404. The resolved URL must be `GET` and on the same origin. If none qualifies, the call fails without opening a session and lists the manifest's endpoints. The success payload now includes `endpoint_url`, and the `url` schema description and docs ask for the full streaming endpoint.

- [#581](https://github.com/winsznx/routedock/pull/581) [`59c72e7`](https://github.com/winsznx/routedock/commit/59c72e7416b68d1fff8e3e9eed9cbacf0bd89ceb) Thanks [@TheWeirdDee](https://github.com/TheWeirdDee)! - `pay_for_data` now rejects a missing, empty, non-string, zero, negative or non-numeric `max_amount` (for example `"$0.01"`) before contacting the provider. Previously these parsed to `NaN`, the price comparison was always false, and the payment went through with no per-request ceiling. Price and `max_amount` are now compared exactly in stroops instead of as floats.

- [#601](https://github.com/winsznx/routedock/pull/601) [`b129d34`](https://github.com/winsznx/routedock/commit/b129d344cf3ee33069372417972f7b42be73ac48) Thanks [@Olalolo22](https://github.com/Olalolo22)! - Gracefully close open MPP sessions with bounded timeout on SIGINT, SIGTERM, and stdio transport close ([#565](https://github.com/winsznx/routedock/issues/565)).

- [#599](https://github.com/winsznx/routedock/pull/599) [`295c372`](https://github.com/winsznx/routedock/commit/295c37203d9c599528bf0df2e0edba5bebd6ad35) Thanks [@Olalolo22](https://github.com/Olalolo22)! - Report current package version from package.json and validate STELLAR_NETWORK at startup ([#568](https://github.com/winsznx/routedock/issues/568)).

- [#625](https://github.com/winsznx/routedock/pull/625) [`aa99d8d`](https://github.com/winsznx/routedock/commit/aa99d8d4980f95fd373c029957780cfc1baa57f5) Thanks [@chiomailekuba](https://github.com/chiomailekuba)! - Enable npm provenance for releases and include repository, homepage, and issue links in package metadata.
